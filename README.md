# 🕵️ Motion Alarm Detection System

This project is a simple yet powerful **Motion Detection Alarm System** using **OpenCV** for real-time video processing and **Pygame** for audio alerts. It detects motion via a webcam, plays an alert sound, and captures images whenever motion is detected.

## 📸 Features

- ✅ Real-time motion detection using OpenCV
- 🔊 Sound alert using Pygame when motion is detected
- 💾 Saves captured images with timestamp
- 🔲 Fullscreen toggle with keyboard shortcut
- 🧹 Noise reduction using morphological operations

## 🚀 Getting Started

### 📦 Requirements

- Pygame
